# Electrical Power System Diagrams | AutoCAD Electrical

## Overview

Welcome to my Electrical Engineering Design Portfolio!

This repository contains three electrical engineering diagrams developed using **AutoCAD Electrical** as part of my practical learning and professional development as an Electrical and Electronic Engineering student.

The projects focus on electrical power system representation, bus arrangements, three-phase connections, and technical drawing presentation. They demonstrate my efforts to develop practical CAD skills and improve my understanding of how electrical systems are documented in engineering practice.

## About the Projects

### 1. Overall Plant Single-Line Diagram

This drawing presents an overall representation of a plant electrical power distribution arrangement using the single-line diagram approach.

Single-line diagrams simplify complex electrical systems by using standardized symbols and single lines to represent electrical connections. They help engineers understand the general arrangement of a power system and communicate its major components in a clear format.

**Skills demonstrated:**
- Single-line diagram drafting
- Electrical power distribution representation
- Electrical symbol placement
- Schematic organization and readability
- AutoCAD Electrical software

### 2. 4.16 kV Bus Three-Line Diagram

This project represents an electrical bus arrangement at the 4.16 kV voltage level using a three-line diagram.

A three-line diagram shows the three phases of a three-phase system separately, allowing individual phase conductors and their connections to be represented in greater detail.

**Skills demonstrated:**
- Three-phase system representation
- Bus arrangement drafting
- Electrical conductor connections
- Technical schematic development
- Electrical drawing presentation

### 3. 7.2 kV Bus Three-Line Diagram

This project presents a three-line electrical diagram for a bus arrangement identified at the 7.2 kV voltage level.

The drawing provided further practice in organizing electrical components, representing phase connections, and preparing readable engineering documentation using CAD software.

**Skills demonstrated:**
- Three-line diagram drafting
- Three-phase electrical representation
- Electrical bus documentation
- CAD layout and drawing organization
- Technical communication
